# DiscSigner

DiscSigner is an experimental, open-source Rust project exploring audio as a way to store and transfer Bitcoin wallet information. The goal is to encode wallet data onto an audio CD and recover it from the analog output of a conventional CD player. Longer term, the project aims to embed Bitcoin data in music while preserving the listening experience and allowing recovery without the original recording.

## Current prototype

The command-line tool encodes text into a 44.1 kHz, 16-bit mono WAV file using two tones and decodes WAV files generated by the encoder. It can also inspect Bitcoin extended public keys (xpubs). The test suite includes an xpub round trip through the audio encoder and decoder. CD playback and music embedding are future work.

## Quick start

With Rust and Cargo installed, run this from the repository root.

```sh
cargo run -- encode "hello" demo.wav
cargo run -- decode demo.wav
cargo test
```

## Source layout

- [`src/main.rs`](src/main.rs) handles command-line arguments.
- [`src/audio.rs`](src/audio.rs) handles audio encoding, decoding, and WAV files.
- [`src/wallet.rs`](src/wallet.rs) parses and serializes extended public keys.
- [`tests/`](tests/) covers the audio and wallet modules and their round trip.

## Security Notice

DiscSigner is experimental software under active development.

It has not undergone an independent security audit and
should not be used to store, recover, or manage real
Bitcoin private keys.

Use only regtest or signet wallets during development.
